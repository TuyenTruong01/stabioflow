# DCA design (future milestone)

No unattended DCA is implemented. The eventual UI must model three strategies separately: bridge on each execution, move the whole budget to Arc once, and Unified Balance only if confirmed by current official documentation. It will compare live estimates rather than asserting a cheapest strategy.

Future plans need amount, frequency, start date, duration/purchases, total budget, maximum slippage, and funding strategy. `cirBTC` remains a proposed first asset, not a supported integration claim.
